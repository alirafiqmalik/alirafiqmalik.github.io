Projects Filter Lab

Every prototype below is live and filters the real project set. Tick boxes to compare them. Nothing here is linked from the site — it exists to be chosen from, then deleted.

What was wrong with the pill row

  • Seven categories over nine projects. Four of the seven returned exactly one project, so the filter worked as a table of contents, not a filter.
  • One choice at a time. "Hardware or security" was not expressible; neither was "the ML work that is also embedded".
  • One flat axis. "Hardware Design" (a discipline), "Network Security" (a domain), and "Machine Learning" (a technique) sat in the same row as if they were the same kind of thing.
  • No counts. Every dead end had to be clicked to be discovered.
  • Alphabetical order. The row opened on "AI & Privacy" because A sorts first, not because it leads.

Picking one

/projects/ currently ships A · Ledger on 1 · Two Axes. Layout and scheme are independent choices: set active_scheme in _data/project_facets.yml to switch taxonomy, and pass variant to project-filters.html to switch layout. The written comparison lives in docs/adr/0002-projects-faceted-filter.md.
